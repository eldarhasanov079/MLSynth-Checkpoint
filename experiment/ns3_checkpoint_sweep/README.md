# ns-3 Checkpoint Sweep (ns3\_checkpoint\_sweep)

This folder is for experiments that use the **ns-3 network backend** in ASTRA-sim, while **reusing the same traces** generated by the analytical-backend checkpoint sweep under `experiment/checkpoint_sweep/`.

For now, it contains a simple wrapper to run the official ns-3 example from the ASTRA-sim docs; we will later add scripts that plug the checkpoint sweep traces into ns-3.

## Layout

- `run_ns3_example.sh` — runs the example ns-3 backend command from the docs, using your external ASTRA-sim clone.
- Traces: **not stored here**. Reuse the ones in `experiment/checkpoint_sweep/traces/`.

## Requirements

- A local ASTRA-sim clone with the ns-3 backend checked out:
  - `extern/network_backend/ns-3` must exist inside your ASTRA-sim tree.
- The ns-3 backend must be built as described in the docs:
  - `bash build/astra_ns3/build.sh`
- Environment variable `ASTRA_SIM_DIR` pointing to your ASTRA-sim clone.

Reference: see the official ns-3 backend documentation (`ns-3 Network Backend — ASTRA-sim`).

## Usage (example sanity check)

From this repo root:

```bash
export ASTRA_SIM_DIR=/path/to/astra-sim
chmod +x experiment/ns3_checkpoint_sweep/run_ns3_example.sh
./experiment/ns3_checkpoint_sweep/run_ns3_example.sh
```

This just verifies that your ns-3 backend build is working. In later steps we will add scripts here that read traces from `experiment/checkpoint_sweep/traces/` and run them through the ns-3 backend.
